# Agente Migro — instaladores

Instaladores do Agente Migro, que grava as ligações dos vendedores (WhatsApp Web, Google Meet e
WhatsApp Desktop) para o painel de ligações da Migro. Este repositório tem só os instaladores;
o agente instalado se atualiza a partir daqui.

Última versão:

- [Windows](https://github.com/eumigro/agente-migro-releases/releases/latest/download/Agente-Migro-Windows.exe)
- [Mac com chip Apple (M1, M2…)](https://github.com/eumigro/agente-migro-releases/releases/latest/download/Agente-Migro-Mac-arm64.dmg)
- [Mac Intel](https://github.com/eumigro/agente-migro-releases/releases/latest/download/Agente-Migro-Mac-x64.dmg)

Para usar, a TI da Migro fornece o endereço do servidor e a chave do computador.
